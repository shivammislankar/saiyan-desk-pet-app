# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities through GitHub private security advisories.

**Do not open public issues for security concerns.**

We will:
- Acknowledge receipt within 48 hours
- Investigate and provide a fix or mitigation
- Credit reporters in release notes (unless they prefer anonymity)

## What to Report

- Vulnerabilities in the application code
- Dependency vulnerabilities
- Configuration issues that could lead to security problems
- Privacy concerns

## What NOT to Report

- Issues already documented in known limitations
- Feature requests
- General bug reports (use regular issues)
