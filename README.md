# Saiyan Desk Pet

A pixel-art martial-artist desktop companion for Windows and macOS. He floats on top of your windows, fights along as you type, fires an energy beam on command and keeps your to-do list.

> **DISCLAIMER:** This is an unofficial, non-commercial fan project. It is not affiliated with, endorsed by or sponsored by Akira Toriyama, Shueisha, Toei Animation, Bandai Namco or any rights holder. The character in this repository is original placeholder art generated by code. Users are responsible for any sprite packs they load.

## Features

- **Transparent, always-on-top pet** in a frameless window that never steals focus
- **Drag and throw** him anywhere; he bounces softly off screen edges and remembers where you left him
- **Still when idle**: no constant wiggling while you work
- **Keyboard combat**: every keypress is a punch or kick (Space = kick, Enter = uppercut, Backspace = block). Modifiers and F-keys never trigger strikes
- **Kamehameha**: double-tap **Alt** to charge ("Ka-me-ha-me… HA!") and fire a beam across your desktop. The beam is purely visual and click-through
- **To-do list**: click him to open a small to-do panel beside him; tasks are saved between restarts
- **Sound effects** (off by default): original synthesised punch, kick, charge and beam sounds
- **Sprite packs**: load your own art, from 64 px pixel art to 256 px high-resolution sheets, sharp at any display scaling
- **Private by design**: no telemetry, nothing leaves your computer (see [Privacy](#privacy))

## Requirements

- Node.js 22.12+
- Windows 10+ or macOS 12+

## Quick Start

```bash
npm install
npm run dev
```

Then look for the orange tray icon (on Windows it may be under the **^** arrow on the taskbar). Click it for **Sound** and **Quit**.

## Controls

| Action | How |
|---|---|
| Move him | Press and drag; release while moving to throw |
| To-do list | Click him (press and release without moving). Click again or press **Esc** to close |
| Strike | Type anywhere |
| Kamehameha | Double-tap **Alt** quickly (within 400 ms). 3-second cooldown |
| Sound on/off | Tray icon → **Sound** |

### Kamehameha caveat

The app never blocks or changes your shortcuts. On Windows a lone Alt tap can still activate the menu bar in some apps, and on macOS Option can affect some apps. If that gets in the way, set `"kamehamehaTrigger": "ctrl"` (or `"shift"`) in your settings file. Alt+Tab and other Alt combinations never fire the attack.

## Sprite Packs

The repository ships an original placeholder character. To use your own art, put a pack in the git-ignored `packs/` folder (or in the app's data folder under `packs/`). See [packs/README.md](packs/README.md) for the format, the `rendering` / `displayScale` options and the local build helpers.

**Never commit copyrighted art.** `packs/`, `assets/goku/sprites/` and `assets/goku/sheets/` are git-ignored for this reason, and installers never include them.

## Development

```bash
npm run dev               # build and run
npm test                  # unit + integration tests
npm run lint              # ESLint (TypeScript)
npm run generate-sprites  # regenerate the original default pack
npm run verify-assets     # check the default pack is complete
npm run check-privacy     # privacy invariants
npm run build:win         # Windows installer + portable exe (release/)
npm run build:mac         # macOS DMG (release/)
```

Builds are unsigned. Windows SmartScreen and some antivirus tools may warn about an unsigned app that uses a global keyboard hook; the source and the privacy checks are all in this repository, and each release publishes SHA-256 checksums.

## Privacy

This application:
- Does NOT record typed text or store which keys were pressed
- Does NOT log raw key codes
- Does NOT send any data to external services
- Does NOT contain telemetry or analytics
- Does NOT suppress or modify ordinary OS keyboard shortcuts

See [docs/privacy.md](docs/privacy.md) for how this is enforced.
